# ESPFanManager v2 — Implementation Plan

> **For Hermes:** Implement this plan task-by-task, following the ESP-IDF example patterns exactly.

**Goal:** Reimplement ESP32-S3 multi-channel smart fan controller from first principles, following ESP-IDF v6.0 conventions, with clean component architecture, event-driven design, and rigorous error handling.

**Architecture:** Component-per-capability design with opaque handles. Each component exposes a public header in `include/`, private implementation in `.c`, and Unity test in `test/`. Inter-component communication via ESP event loop. All functions return `esp_err_t`.

**Tech Stack:** ESP-IDF v6.0.1, ESP32-S3, FreeRTOS, LEDC, PCNT, ADC Oneshot, esp_http_server, LittleFS, NVS, cJSON, Unity test framework.

## v2 Design Principles (Lessons from v1)

1. **Opaque handles** — components return `*_handle_t`, not exposed struct pointers. Callers use getter/setter functions.
2. **esp_err_t everywhere** — no void functions that can silently fail. Every operation returns a status.
3. **ESP event bus** — components communicate via `esp_event_post()`, not direct cross-component calls. WiFi→HTTP lifecycle, source stale→failsafe all go through events.
4. **Static alloc where possible** — pre-allocate max-config arrays at init. No malloc in hot paths.
5. **Kconfig-driven** — compile-time config for max fans, max curves, pin defaults, timing params.
6. **Tagged logging** — every component has a `static const char *TAG` for ESP_LOG macros.
7. **ESP_ERROR_CHECK on all HW ops** — no unchecked peripheral calls.
8. **Unity tests per component** — testable pure logic extracted, HW-dependent code tested on device.

```c
#include "esp_task_wdt.h"

void app_main(void) {
    // ... NVS init ...
    
    // Init TWDT, subscribe main task during boot
    const esp_task_wdt_config_t twdt_config = {
        .timeout_ms = 5000,
        .idle_core_mask = 0,
        .trigger_panic = true,
    };
    ESP_ERROR_CHECK(esp_task_wdt_init(&twdt_config));
    ESP_ERROR_CHECK(esp_task_wdt_add(NULL));  // subscribe current task
    ESP_LOGI(TAG, "TWDT initialized (5s timeout)");
    
    // ... after WiFi connected, unsubscribe main task ...

    ESP_LOGI(TAG, "TWDT: main task unsubscribed");
    
    while (1) { vTaskDelay(pdMS_TO_TICKS(10000)); }
}
```

### Task 2.2: Hysteresis Filter

**Objective:** Deadband around target duty to prevent fan oscillation. If current duty is within ±N% of target, hold current duty.

**Implemented in:** `components/f_control/f_control.c` (private function)

**Logic:**
```c
static uint8_t apply_hysteresis(uint8_t current, uint8_t target, uint8_t threshold_pct) {
    int diff = (int)target - (int)current;
    if (abs(diff) <= threshold_pct) return current;  // within deadband, hold
    return target;
}
```

### Task 2.3: Ramp-Up / Ramp-Down Slew-Rate Limiter

**Objective:** Limit duty change rate with separate ramp-up and ramp-down speeds. Ramp up (toward higher duty) at `max_up_pct` per tick. Ramp down (toward lower duty) at `max_down_pct` per tick. Prevents sudden jumps and audible pulsing.

**Implemented in:** `components/f_control/f_control.c` (private function)

**Logic:**
```c
static uint8_t apply_slew_rate(uint8_t current, uint8_t target, uint8_t max_up_pct, uint8_t max_down_pct) {
    if (target > current) {
        // Ramping UP: limit by max_up_pct
        uint8_t step = (target - current > max_up_pct) ? current + max_up_pct : target;
        return step;
    } else if (target < current) {
        // Ramping DOWN: limit by max_down_pct
        uint8_t step = (current - target > max_down_pct) ? current - max_down_pct : target;
        return step;
    }
    return current; // no change
}
```

**Design rationale:**
- Ramp-up typically faster (e.g., 10%/tick) — cooling response should be quick
- Ramp-down typically slower (e.g., 3%/tick) — avoids audible fan speed pulsing
- Both rates configurable at runtime via `f_control_set_ramp_rates()`

**Verification:** Unit test via test_f_control.c:
- Ramp up: current=30, target=80, max_up=10, max_down=5 → returns 40 (capped by up rate)
- Ramp down: current=80, target=30, max_up=10, max_down=5 → returns 75 (capped by down rate)
- No change: current=50, target=50 → returns 50

```c
static void initialize_sntp(void) {
    esp_sntp_setoperatingmode(SNTP_OPMODE_POLL);

    esp_sntp_init();

}
```

### Task 4.2: f_schedule Schedule Service

**Objective:** Timer-based schedule evaluation every 60s. For each active schedule rule: if current time is within [start, end] window, override fan duty. Non-destructive — fan returns to base mode when schedule expires.

**Depends on:** 4.1 (SNTP), 1.5 (f_fan)

**Files:**
- Create: `components/f_schedule/CMakeLists.txt`
- Create: `components/f_schedule/include/f_schedule.h`
- Create: `components/f_schedule/f_schedule.c`
- Create: `components/f_schedule/test/test_f_schedule.c`
- Create: `components/f_schedule/test/CMakeLists.txt`

**f_schedule.h:**
```c
#pragma once
#include "esp_err.h"
#include "f_core.h"
#include "f_fan.h"
#include <stdint.h>
#include <stdbool.h>

typedef struct {
    uint8_t id;
    uint8_t fan_id;
    uint16_t start_min;  // minutes since midnight (e.g., 8:00 = 480)
    uint16_t end_min;    // minutes since midnight (e.g., 18:00 = 1080)
    uint8_t duty;
    bool enabled;
} f_schedule_info_t;

typedef struct f_schedule *f_schedule_handle_t;

esp_err_t f_schedule_init(f_schedule_handle_t *handle, f_fan_handle_t fan);
esp_err_t f_schedule_add(f_schedule_handle_t handle, const f_schedule_info_t *info, uint8_t *id_out);
esp_err_t f_schedule_remove(f_schedule_handle_t handle, uint8_t id);
esp_err_t f_schedule_start(f_schedule_handle_t handle);
uint8_t f_schedule_get_count(f_schedule_handle_t handle);
```

**f_schedule.c implementation notes:**
- `f_schedule_init()` creates a FreeRTOS timer with 60s period
- Timer callback evaluates all enabled schedules:
  1. Get current time via `gettimeofday()`
  2. Compute minutes-since-midnight
  3. For each schedule: if `start_min <= now_min < end_min`, apply override duty via `f_fan_set_duty()`
  4. If schedule expired (was active last tick, now not), restore fan to base mode
- `f_schedule_add()` validates fan_id exists, stores rule in static array (max 8)

**test_f_schedule.c:**
- Test time-in-window check: 500 in [480, 1080] → true
- Test time-outside-window: 100 in [480, 1080] → false
- Test midnight wrap: schedule 22:00–02:00, check 23:00 → true

**Verification:** `idf.py build` with tests → success.

**Files:**

**app_main() flow:**
```c
void app_main(void) {
    // 1. NVS init
    // 2. TWDT init, subscribe main
    // 3. Initialize hardware drivers
    f_adc_init(&adc);
    f_ds18b20_init(&ds18b20, CONFIG_ESPFM_ONEWIRE_GPIO);
    f_ledc_init(&ledc, 25000, LEDC_TIMER_11_BIT);
    f_pcnt_init(&pcnt);
    // 4. Initialize registries (order matters)
    f_gpio_init(&gpio);
    f_fan_init(&fan, ledc, pcnt);
    f_source_init(&source, adc, ds18b20);
    f_curve_init(&curve);
    // 5. Initialize config, load saved state
    f_config_init(&config, "storage", "/littlefs");
    f_config_load_all(config, fan, source, curve, NULL);
    // 6. Initialize schedule (after config load, before WiFi)
    f_schedule_init(&schedule, fan);
    // 7. WiFi connect
    f_wifi_init(&wifi);
    f_wifi_wait_connected(wifi, pdMS_TO_TICKS(30000));
    // 8. SNTP sync
    initialize_sntp();
    // 9. HTTP init (event-driven start via WiFi events)
    f_http_init(&http);
    // 10. Unsubscribe main from TWDT
    esp_task_wdt_delete(NULL);
    // 11. Start control engine + schedule
    f_control_init(&control, fan, source, curve);
    f_control_start(control);
    f_schedule_start(schedule);
    // 12. Idle loop
    ESP_LOGI(TAG, "ESPFanManager v2.0.0 ready");
    while (1) { vTaskDelay(pdMS_TO_TICKS(60000)); }
}
```

**Verification:** `idf.py build` → success. Flash, verify all components start, WiFi connects, HTTP starts.
